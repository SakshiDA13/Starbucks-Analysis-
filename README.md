# Starbucks-Analysis-
Executive Summary
The dataset contains 33 Starbucks beverages.
The average sugar content across all beverages is 193.78.
The average calorie count is 32.90.
The average caffeine content is 81.69 mg.
Calorie Analysis
Signature beverages have the highest average calories.
Coffee has the lowest average calories, making it the best option for calorie-conscious customers.
Frappuccino categories are among the highest-calorie beverage groups.
Beverages distribution 
Classic Espresso represents the largest share of beverages (around 21%).
Other categories such as Frappuccino, Tea, Smoothies, and Signature beverages contribute smaller but comparable proportions.

Overview 
"This dashboard analyzes 33 Starbucks beverages using Power BI. It highlights KPIs such as average sugar (193.78), calories (32.90), and caffeine (81.69 mg). Coffee has the highest caffeine but the lowest calories, while Signature and Frappuccino drinks are higher in calories and sugar. The dashboard also identifies the top five caffeinated beverages and shows Starbucks' global presence. These insights can help Starbucks optimize product offerings and target different customer segments effectively."
